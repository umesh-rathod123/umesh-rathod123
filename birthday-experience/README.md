# THE NEXT CHAPTER — 20 ✦

A cinematic, interactive birthday experience made for Umesh Rathod's 20th birthday.

## Features
- Animated starfield background
- Responsive, premium dark design with gold accents
- Scroll reveal animations
- Interactive CSS birthday cake — tap the candle to make a wish
- Confetti celebration
- Optional tiny birthday melody generated with the Web Audio API
- Personal timeline and motivational chapter notes
- No frameworks, build tools, or dependencies required

## Run locally
Open `index.html` in any modern browser.

## Deploy with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the branch containing this project and the folder where `index.html` lives.
4. Save, then wait for GitHub Pages to publish.

Built with HTML, CSS and vanilla JavaScript.
